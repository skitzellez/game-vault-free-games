Downloads used by the **FREE GAMES** tab of [Game Vault by Skitzelles](https://github.com/skitzellez/xbox-game-vault).

Everything here may be passed on free of charge. Nothing here is for sale.

- **Freeware:** games their owners released as freeware (Bio Menace, Alien Carnage, Major Stryker, Xargon, Xenophage, Sango Fighter, One Must Fall 2097) and two released under Creative Commons (Electro Man, Traffic Department 2192).
- **Shareware episodes:** the free first episodes (Duke Nukem 3D, Duke Nukem, Duke Nukem II, Heretic, Rise of the Triad, Jazz Jackrabbit, Jill of the Jungle, Epic Pinball, Death Rally, Stargunner, Ken's Labyrinth), shared under the licence that comes with each one.

Each download keeps the **original archive exactly as released** (in `ORIGINAL\`, with its licence), next to the same files unpacked so the game starts at once. None of the games' files are changed; where a game needed it, a settings file made with the game's own setup program (Sound Blaster) was added. Each zip has an `ABOUT.TXT`.

Rights holders: if you want something taken down, [open an issue](https://github.com/skitzellez/game-vault-free-games/issues) and it will be removed.

## 🎮 The Game Vault family

Game Vault is one launcher plus emulators built to work with it. **Install [Game Vault](https://github.com/skitzellez/xbox-game-vault) and it sets these up for you**; press **RT** in Game Vault to update them all.

**Apps**

| Project | What it is | Runs on |
|---|---|---|
| [Game Vault](https://github.com/skitzellez/xbox-game-vault) | The launcher: plug in a USB drive, pick a game, play. Sets up everything below by itself. | Xbox Series X&#124;S |
| [Game Vault for Android](https://github.com/skitzellez/game-vault-android) | The same game library for phones, tablets and Android TV (beta). | Android |
| [Game Vault for iPhone](https://github.com/skitzellez/game-vault-ios) | The Game Vault look on iPhone (early test). | iPhone |
